# Rev B deviations and explicit limits
Original upstream deviation list is preserved in ORIGINAL_ARCHIVES and the original handover.

1. Isolated synthetic candidate folder used; no authorised repository/Windows path exists, so no repository, branch or commit was created. Owner's specific handover permission controls this exception to the generic repository instruction.
2. Tests and GUI ran on Linux Python3.12.14/PySide6 6.12.0, Qt offscreen. This is genuine executed Qt software but does not satisfy the real-Windows quality gate.
3. Geometry uses explicit float tolerances in candidate code; owner Q10 remains unapproved for final architecture. Exact decimal scenario/cost arithmetic and rational reference oracles are separately implemented.
4. A lightweight QPainter 3D projected-mesh viewer reuses PySide6 instead of adding VTK/PyVista. It has painter-depth and industrial-scale limits, no qualified CAD rendering, no clipping/STEP or binary-STL support. See OI-017/018.
5. Schema2 is additive and checksum-controlled but NOT OWNER FROZEN. Schema1 creation and baseline tests are retained unchanged; upgrade is explicit in each synthetic case. Saved and unsaved pre-upgrade backups retained.
6. Several later packages have functioning independent software slices. None are represented as a complete work package, qualified method or full product. WP05 is a refusal interface, not a physical flame model; WP12 is readiness evidence, not independent acceptance.
7. Offline AI replay has no live transport, no official provider endpoint and no real credentials; no provider was silently substituted. It is clearly an offline test harness.
8. Word/PDF/XLSX reports use optional Python exporter libraries in the app rather than an authoring-time service; this keeps the requested Windows product offline. They are development register exports with source/value QA, not engineering conclusions.
9. Existing Word/PDF renderers were used only for local QA. Test screenshots are explicitly Linux offscreen. Native Windows Office/Excel visual verification has not run.
10. No licensed standard text or manufacturer performance data was obtained. No standards-specific engineering assertion, acceptance target, detector curve or sign-off was invented.
